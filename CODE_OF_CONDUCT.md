# Code of conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, assume good intent, criticise code and ideas rather than people, and keep
discussions on topic. Harassment, insults and personal attacks are not welcome.

Problems can be reported privately through **Security → Report a vulnerability** on this repository
(choose it even for conduct issues; it reaches the maintainer privately). The maintainer may edit or
remove comments, and block people who keep breaking these rules.
